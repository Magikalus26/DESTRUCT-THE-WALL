# DESTRUCT THE WALL

Jeu d'évasion et de destruction incrémentale à la première personne en WebGL / Three.js, optimisé pour Safari iOS (PWA écran d'accueil `390×844`) et Desktop.

Jouer en ligne : https://magikalus26.github.io/DESTRUCT-THE-WALL/

## Développement local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```
